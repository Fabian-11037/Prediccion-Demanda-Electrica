10.7. N-HiTS: interpolación jerárquica residual#

La notación y las operaciones compartidas definen los tensores, el nivel de demanda, la atención, las activaciones y la optimización.

Arquitectura y fundamentos#

N-HiTS construye el pronóstico por contribuciones de distinta resolución. Un bloque explica una parte de la historia y propone una parte de la salida; el siguiente trabaja con el residuo que queda. La interpolación permite que un bloque describa el horizonte con pocos nodos, mientras otro añade variaciones más finas.

La implementación tiene tres bloques oficiales de N-HiTS con MLP de ancho 512, agrupamientos temporales 2, 2 y 1 y factores de reducción de salida 4, 2 y 1. Para 24 horas se predicen respectivamente 6, 12 y 24 nodos. Una matriz fija realiza interpolación lineal equivalente a interpolate(..., align_corners=False). Cada bloque usa la historia residual, 59 exógenas históricas —29 variables distintas de demanda y 30 máscaras— y las 23 variables de calendario conocidas.

\[\theta_b=f_b(\operatorname{pool}_b(r_b),X_{exo},F),\quad \widehat b_b=\theta_b^{back},\quad \widehat f_b=I_b\theta_b^{for},\qquad r_{b+1}=r_b-\widehat b_b.\]

El pronóstico normalizado empieza en el último valor de demanda de la ventana y suma \(\sum_b\widehat f_b\). El backcast reconstruye historia; no es una etiqueta futura ni una segunda serie objetivo. El modelo devuelve \(\widehat{\mathbf y}=\ell_t\widehat{\mathbf r}\). Su configuración seleccionada N14 contiene 17.489.442 parámetros. Este tamaño se explica por las entradas multivariadas aplanadas de los bloques y no implica, por sí mismo, mayor capacidad predictiva efectiva.

El modelo reutiliza el preparador y el optimizador numérico de PatchTST, pero la red es diferente y no incorpora su lectura afín. Se conserva el procesamiento multiescala, el esquema residual y la interpolación. Las fuentes, licencia y revisión de NeuralForecast acompañan al código.

Esquema global#

Los tres bloques explican progresivamente la historia y suman contribuciones al pronóstico. Las salidas interpoladas de 6, 12 y 24 nudos se añaden al último nivel observado.

Detalle de las operaciones#

Cada bloque agrupa historia y exógenas, calcula coeficientes con un MLP y separa backcast y pronóstico. El backcast se resta de la historia; la interpolación fija lleva los nudos a las 24 horas del horizonte.

El código de exportación de los esquemas forma parte del preprocesamiento compartido.

23class NHITSNumerico(nn.Module):
24    """Tres bloques oficiales, con exógenas históricas y calendario conocido."""
25    def __init__(self, p, sigma_demanda, L=168, H=24):
26        super().__init__()
27        self.sigma_demanda = float(sigma_demanda)
28        self.blocks = nn.ModuleList([
29            NHITSBlock(input_size=L, h=H, n_theta=L + H // factor,
30                mlp_units=[[512, 512]] * 3,
31                basis=BaseLinealDeterminista(L, H, H // factor),
32                futr_input_size=23, hist_input_size=59, stat_input_size=0,
33                n_pool_kernel_size=pool, pooling_mode='MaxPool1d',
34                dropout_prob=p['dropout'], activation='ReLU')
35            for pool, factor in zip([2, 2, 1], [4, 2, 1])])
36
37    def forward(self, x, cal):
38        # Reconstrucción exacta de demanda/nivel, no de etiquetas futuras.
39        demanda = 1 + x[:, :, 0] * self.sigma_demanda
40        historicas = torch.cat([x[:, :, 1:30], x[:, :, 53:83]], dim=2)
41        calendario = torch.cat([x[:, :, 30:53], cal], dim=1)
42        residual = demanda.flip(dims=(-1,))
43        pronostico = demanda[:, -1:, None]
44        for bloque in self.blocks:
45            backcast, contribucion = bloque(residual, calendario, historicas, None)
46            residual = residual - backcast
47            pronostico = pronostico + contribucion
48        return pronostico.squeeze(-1)

python scripts/entrenar_arquitectura.py --modelo nhits --fase prueba --allow-test --semilla 1000 --dispositivo auto --salida salidas/nhits_prueba_1000

El código completo de preparación, optimización, guardado y restauración está en el pipeline ejecutable compartido. Cada salida debe ser una carpeta nueva.

La preparación conserva 30 variables históricas, 23 de calendario y 30 máscaras. Se usan las mismas ventanas para ajuste, parada y prueba, con imputaciones y escalas estimadas solo en ajuste. El motor recibe el dispositivo explícitamente, guarda el mínimo de parada interna y convierte la salida normalizada a kWh. El código de la arquitectura incluye el motor para PatchTST; N-HiTS comparte ese motor sin compartir su red.

  8class _IdentityBasis(nn.Module):
  9    def __init__(
 10        self,
 11        backcast_size: int,
 12        forecast_size: int,
 13        interpolation_mode: str,
 14        out_features: int = 1,
 15    ):
 16        super().__init__()
 17        assert (interpolation_mode in ["linear", "nearest"]) or (
 18            "cubic" in interpolation_mode
 19        )
 20        self.forecast_size = forecast_size
 21        self.backcast_size = backcast_size
 22        self.interpolation_mode = interpolation_mode
 23        self.out_features = out_features
 24
 25    def forward(self, theta: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
 26
 27        backcast = theta[:, : self.backcast_size]
 28        knots = theta[:, self.backcast_size :]
 29
 30        # Interpolation is performed on default dim=-1 := H
 31        knots = knots.reshape(len(knots), self.out_features, -1)
 32        if self.interpolation_mode in ["nearest", "linear"]:
 33            # knots = knots[:,None,:]
 34            forecast = F.interpolate(
 35                knots, size=self.forecast_size, mode=self.interpolation_mode
 36            )
 37            # forecast = forecast[:,0,:]
 38        elif "cubic" in self.interpolation_mode:
 39            if self.out_features > 1:
 40                raise Exception(
 41                    "Cubic interpolation not available with multiple outputs."
 42                )
 43            batch_size = len(backcast)
 44            knots = knots[:, None, :, :]
 45            forecast = torch.zeros(
 46                (len(knots), self.forecast_size), device=knots.device
 47            )
 48            n_batches = int(np.ceil(len(knots) / batch_size))
 49            for i in range(n_batches):
 50                forecast_i = F.interpolate(
 51                    knots[i * batch_size : (i + 1) * batch_size],
 52                    size=self.forecast_size,
 53                    mode="bicubic",
 54                )
 55                forecast[i * batch_size : (i + 1) * batch_size] += forecast_i[
 56                    :, 0, 0, :
 57                ]  # [B,None,H,H] -> [B,H]
 58            forecast = forecast[:, None, :]  # [B,H] -> [B,None,H]
 59
 60        # [B,Q,H] -> [B,H,Q]
 61        forecast = forecast.permute(0, 2, 1)
 62        return backcast, forecast

 64ACTIVATIONS = ["ReLU", "Softplus", "Tanh", "SELU", "LeakyReLU", "PReLU", "Sigmoid"]

 68class NHITSBlock(nn.Module):
 69    """
 70    NHITS block which takes a basis function as an argument.
 71    """
 72
 73    def __init__(
 74        self,
 75        input_size: int,
 76        h: int,
 77        n_theta: int,
 78        mlp_units: list,
 79        basis: nn.Module,
 80        futr_input_size: int,
 81        hist_input_size: int,
 82        stat_input_size: int,
 83        n_pool_kernel_size: int,
 84        pooling_mode: str,
 85        dropout_prob: float,
 86        activation: str,
 87    ):
 88        super().__init__()
 89
 90        pooled_hist_size = int(np.ceil(input_size / n_pool_kernel_size))
 91        pooled_futr_size = int(np.ceil((input_size + h) / n_pool_kernel_size))
 92
 93        input_size = (
 94            pooled_hist_size
 95            + hist_input_size * pooled_hist_size
 96            + futr_input_size * pooled_futr_size
 97            + stat_input_size
 98        )
 99
100        self.dropout_prob = dropout_prob
101        self.futr_input_size = futr_input_size
102        self.hist_input_size = hist_input_size
103        self.stat_input_size = stat_input_size
104
105        assert activation in ACTIVATIONS, f"{activation} is not in {ACTIVATIONS}"
106        assert pooling_mode in POOLING, f"{pooling_mode} is not in {POOLING}"
107
108        activ = getattr(nn, activation)()
109
110        self.pooling_layer = getattr(nn, pooling_mode)(
111            kernel_size=n_pool_kernel_size, stride=n_pool_kernel_size, ceil_mode=True
112        )
113
114        # Block MLPs
115        hidden_layers = [
116            nn.Linear(in_features=input_size, out_features=mlp_units[0][0])
117        ]
118        for layer in mlp_units:
119            hidden_layers.append(nn.Linear(in_features=layer[0], out_features=layer[1]))
120            hidden_layers.append(activ)
121
122            if self.dropout_prob > 0:
123                # raise NotImplementedError('dropout')
124                hidden_layers.append(nn.Dropout(p=self.dropout_prob))
125
126        output_layer = [nn.Linear(in_features=mlp_units[-1][1], out_features=n_theta)]
127        layers = hidden_layers + output_layer
128        self.layers = nn.Sequential(*layers)
129        self.basis = basis
130
131    def forward(
132        self,
133        insample_y: torch.Tensor,
134        futr_exog: torch.Tensor,
135        hist_exog: torch.Tensor,
136        stat_exog: torch.Tensor,
137    ) -> Tuple[torch.Tensor, torch.Tensor]:
138
139        # Pooling
140        # Pool1d needs 3D input, (B,C,L), adding C dimension
141        insample_y = insample_y.unsqueeze(1)
142        insample_y = self.pooling_layer(insample_y)
143        insample_y = insample_y.squeeze(1)
144
145        # Flatten MLP inputs [B, L+H, C] -> [B, (L+H)*C]
146        # Contatenate [ Y_t, | X_{t-L},..., X_{t} | F_{t-L},..., F_{t+H} | S ]
147        batch_size = len(insample_y)
148        if self.hist_input_size > 0:
149            hist_exog = hist_exog.permute(0, 2, 1)  # [B, L, C] -> [B, C, L]
150            hist_exog = self.pooling_layer(hist_exog)
151            hist_exog = hist_exog.permute(0, 2, 1)  # [B, C, L] -> [B, L, C]
152            insample_y = torch.cat(
153                (insample_y, hist_exog.reshape(batch_size, -1)), dim=1
154            )
155
156        if self.futr_input_size > 0:
157            futr_exog = futr_exog.permute(0, 2, 1)  # [B, L, C] -> [B, C, L]
158            futr_exog = self.pooling_layer(futr_exog)
159            futr_exog = futr_exog.permute(0, 2, 1)  # [B, C, L] -> [B, L, C]
160            insample_y = torch.cat(
161                (insample_y, futr_exog.reshape(batch_size, -1)), dim=1
162            )
163
164        if self.stat_input_size > 0:
165            insample_y = torch.cat(
166                (insample_y, stat_exog.reshape(batch_size, -1)), dim=1
167            )
168
169        # Compute local projection weights and projection
170        theta = self.layers(insample_y)
171        backcast, forecast = self.basis(theta)
172        return backcast, forecast
