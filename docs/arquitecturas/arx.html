10.2. ARX lineal regularizado#

La notación y las operaciones compartidas definen los tensores, el nivel de demanda, la atención, las activaciones y la optimización.

Arquitectura y fundamentos#

ARX relaciona la demanda futura con sus propios rezagos y con variables externas conocidas: aquí, el calendario. Cada una de las 24 horas tiene una combinación lineal distinta de los mismos atributos. Una subida de un rezago produce un cambio proporcional determinado por su coeficiente; no hay capas ocultas ni interacciones aprendidas entre atributos. Es una referencia de complejidad baja para valorar si las redes justifican su coste.

La entrada contiene los últimos 48 valores de demanda divididos por el nivel de la ventana y las 23 variables de calendario de cada una de las 24 horas futuras: \(48+24\times23=600\) atributos. Aunque la ventana que calcula el nivel tiene 168 horas, la regresión utiliza directamente 48 rezagos. Cada atributo se estandariza con la media y desviación del tramo de ajuste.

\[z_j=\frac{u_j-\mu_j}{s_j},\qquad \widehat{\mathbf r}=Wz+b,\qquad \widehat{\mathbf y}=\ell_t\widehat{\mathbf r}.\]

Aquí \(W\in\mathbb R^{24\times600}\) y \(b\in\mathbb R^{24}\); hay 14.424 parámetros entrenables. La configuración seleccionada utiliza Lasso, con \(\lambda=1,3734\times10^{-7}\). Se minimiza el MAE normalizado más \(\lambda\sum_{h,j}|W_{hj}|\), lo que favorece coeficientes pequeños o nulos. La penalización actúa sobre los pesos, no sobre los sesgos. Los valores de escalado se conservan junto al checkpoint; no se vuelven a estimar en prueba.

Esquema global#

La historia se divide por su nivel y se seleccionan 48 rezagos. La concatenación con el calendario produce 600 atributos; una matriz genera las 24 salidas.

Detalle de las operaciones#

Cada hora utiliza una fila distinta de la matriz de pesos. El sesgo completa la combinación lineal; la pérdida incorpora penalización lasso y el pronóstico se restituye a kWh con el nivel de la ventana.

El código de exportación de los esquemas forma parte del preprocesamiento compartido.

35class Tabular(nn.Module):
36    """Entrada tabular calculada en el propio dispositivo: historia de demanda, resumen de las
37    demás entradas y calendario del horizonte, estandarizados con estadísticas de entrenamiento."""
38
39    def __init__(s, n_x, lags, H, kc):
40        super().__init__()
41        s.n_x, s.lags = n_x, lags
42        s.d = lags + 3 * (n_x - 1) + H * kc
43        s.register_buffer("mu", torch.zeros(s.d))
44        s.register_buffer("sd", torch.ones(s.d))
45
46    def feats(s, xp, cf):
47        partes = [xp[:, -s.lags:, 0]]
48        if s.n_x > 1:
49            e = xp[:, :, 1: s.n_x]
50            partes += [e[:, -1], e[:, -24:].mean(1), e.mean(1)]
51        partes.append(cf.flatten(1))
52        return torch.cat(partes, 1)
53
54    @torch.no_grad()
55    def preparar(s, xp, cf):  # solo con entrenamiento
56        f = torch.cat([s.feats(xp[i:i + 2048], cf[i:i + 2048]) for i in range(0, len(xp), 2048)])
57        s.mu.copy_(f.mean(0))
58        s.sd.copy_(f.std(0).clamp_min(1e-6))
59
60    def entrada(s, xp, cf):
61        return (s.feats(xp, cf) - s.mu) / s.sd
62
63    def penalizacion(s):
64        return 0.0
65
66class ARXLineal(Tabular):
67    def __init__(s, n_x, lags, H, kc, penalizacion, lam):
68        super().__init__(n_x, lags, H, kc)
69        s.lin = nn.Linear(s.d, H)
70        s.pen, s.lam = penalizacion, lam
71
72    def forward(s, xp, cf):
73        return s.lin(s.entrada(xp, cf))
74
75    def penalizacion(s):
76        w = s.lin.weight
77        return s.lam * ((w ** 2).sum() if s.pen == "ridge" else w.abs().sum())

El procedimiento separa ajuste, parada interna y evaluación externa, estima las transformaciones únicamente en ajuste y restaura el mínimo de parada. La función admite validación o prueba con autorización explícita y conserva las salidas en una carpeta nueva. Los bloques siguientes documentan el código; construir el libro no ejecuta entrenamientos.

10    def __init__(self, panel, registro, cfg, posiciones_train, secuencial=False):
11        super().__init__(panel, registro, cfg)
12        pos=np.asarray(posiciones_train)
13        inicio=panel.index[pos.min()-cfg.ventana]
14        fin=panel.index[pos.max()-1]
15        filas=panel.loc[(panel.index>=inicio)&(panel.index<=fin)]

18        self.escala.std_=filas[cols].std().replace(0,1.)

20        target='y_demanda_real_kwh'

23        self.secuencial=False
24        train=super().conjunto_pos(pos)
25        self.sigma_demanda=max(float(train.x[:,:,0].std()),1e-6)
26        self.secuencial=secuencial
27        self.auditoria=dict(inicio_ajuste=str(inicio),fin_ajuste=str(fin),filas=len(filas),sigma_demanda=self.sigma_demanda,secuencial=secuencial,
28            descripcion_escala_mase='Fija 2000–2017, como denominador de referencia de la ejecución original; no participa en optimización')
29    def conjunto_pos(self,pos,clave=None):
30        c=super().conjunto_pos(pos,clave)
31        if self.secuencial:
32            c.x[:,:,0]=(c.x[:,:,0]-1.)/self.sigma_demanda
33        return c
34    def escaladores(self):
35        return dict(media=self.escala.media_.to_dict(),std=self.escala.std_.to_dict(),columnas_x=self.cols_x,columnas_cal=self.cols_cal,
36            escala_mase=self.escala_mase,datos=asdict(self.cfg),**self.auditoria)
37
38class Secuencial(nn.Module):
39    def __init__(self,nombre,p,tr):
40        super().__init__();self.nombre=nombre
41        f=tr.x.shape[2]+tr.cal_p.shape[2];L=tr.x.shape[1];H,k=tr.cal_f.shape[1:]
42        if nombre=='lstm':
43            w=int(p['unidades']);self.encoder=nn.LSTM(f,w,num_layers=1,batch_first=True);d=w
44        else:
45            w=int(p['filtros']);kernel=int(p['kernel'])
46            self.encoder=nn.Sequential(nn.Conv1d(f,w,kernel,padding=kernel//2),nn.ReLU(),nn.Dropout1d(p['dropout']),nn.AvgPool1d(2),nn.Flatten());d=w*(L//2)
47        self.drop=nn.Dropout(p['dropout']);self.salida=nn.Linear(d+H*k,H)
48        # Predicción inicial próxima al nivel; aprende desviaciones horarias.
49        nn.init.zeros_(self.salida.bias)
50    def forward(self,x,c):
51        if self.nombre=='lstm':_,(h,_)=self.encoder(x);z=h[-1]
52        else:z=self.encoder(x.transpose(1,2))
53        return 1.+self.salida(torch.cat([self.drop(z),c.flatten(1)],1))
54    def preparar(self,x,c):pass
55    def penalizacion(self):return 0.
56
57class Entrenador(M.ModeloTorch):
58    def ajustar(self,tr,va,datos,p,semilla,op):
59        M.fijar_semillas(semilla,op);self.dev=dev=M.resolver_dispositivo(op.dispositivo)
60        self.red=red=(Secuencial(self.nombre,p,tr) if self.nombre in ('lstm','cnn1d') else M.construir_red(self.nombre,p,tr)).to(dev)
61        xt,ct,yt=self._tensores(tr,datos.objetivo_norm(tr),dev,True)
62        xv,cv,yv=self._tensores(va,datos.objetivo_norm(va),dev,True)
63        red.preparar(xt,ct)
64        lossf={'mse':nn.MSELoss(),'mae':nn.L1Loss(),'huber':nn.HuberLoss(delta=.05)}[p['perdida']]
65        opt=torch.optim.AdamW(red.parameters(),lr=p['lr'],weight_decay=p.get('weight_decay',0.))
66        sched=(torch.optim.lr_scheduler.ReduceLROnPlateau(opt,factor=.5,patience=2) if p['scheduler']=='plateau' else
67            torch.optim.lr_scheduler.CosineAnnealingLR(opt,T_max=op.max_epocas) if p['scheduler']=='cosine' else None)
68        best=reference=float('inf');state=None;stale=0;hist=[];gen=torch.Generator().manual_seed(semilla)
69        bs=int(p['batch_size'])
70        for ep in range(1,op.max_epocas+1):
71            red.train();tot=0.
72            for ix in torch.randperm(len(xt),generator=gen).split(bs):
73                ix=ix.to(dev);opt.zero_grad(set_to_none=True)
74                loss=lossf(red(xt[ix],ct[ix]),yt[ix]);objective=loss+red.penalizacion()
75                if not torch.isfinite(objective):raise FloatingPointError('Pérdida no finita')
76                objective.backward();nn.utils.clip_grad_norm_(red.parameters(),op.clip);opt.step();tot+=float(loss.detach())*len(ix)
77            red.eval()
78            with torch.no_grad():
79                vl=sum(float(lossf(red(xv[i:i+512],cv[i:i+512]),yv[i:i+512]))*len(xv[i:i+512]) for i in range(0,len(xv),512))/len(xv)
80            hist.append(dict(epoca=ep,train_loss=tot/len(xt),val_loss=vl,lr=opt.param_groups[0]['lr']))
81            if vl<best:
82                best=vl;state={k:v.detach().clone() for k,v in red.state_dict().items()}
83            if not np.isfinite(reference) or vl<reference-max(1e-6,.002*abs(reference)):
84                reference=vl;stale=0
85            else:stale+=1
86            if sched is not None:sched.step(vl) if p['scheduler']=='plateau' else sched.step()
87            callback=getattr(self,'observador',None)
88            if callback:callback(hist[-1])
89            if ep>=10 and stale>=6:break
90        red.load_state_dict(state)
91        return dict(n_parametros=sum(v.numel() for v in red.parameters()),epocas=len(hist),mejor_epoca=int(np.argmin([v['val_loss'] for v in hist])+1),dispositivo=str(dev),historia=hist)

from pathlib import Path
import json,sys
import numpy as np
import pandas as pd

def ejecutar_configuracion(raiz, familia, semilla=1000, dispositivo='auto',
                          fase='validacion', anio=2021, permitir_prueba=False,
                          salida=None):
    raiz=Path(raiz).resolve()
    procedencia=json.loads((raiz/'results/jbook/modelos_actualizados.json').read_text())
    fuentes=raiz/'results/repositorio'/procedencia['commit']
    sys.path.insert(0,str(fuentes/'src'))
    from demanda import modelos_base as M, particion as P
    from demanda import reentrenamiento_v3 as motor
    from demanda.variantes_v4 import Secuencial as Recurrente
    from demanda.metricas import evaluar
    import torch
    registro=json.loads((fuentes/'results/consolidado/modelos.json').read_text())
    config=registro[familia]['configuracion']
    panel=pd.read_parquet(raiz/'data/processed/panel_horario.parquet')
    variables=json.loads((fuentes/'data/processed/feature_registry.json').read_text())
    cfg=M.ConfigDatos(ventana=config['ventana'])
    if fase=='prueba':
        if not permitir_prueba:raise PermissionError('La prueba requiere acceso explícito')
        tr,es=P.pretest(panel.index,ventana=cfg.ventana)
        ev=P.origenes(panel.index,'test',ventana=cfg.ventana,allow_test=True)
    else:
        fold=P.folds_forward_chaining(panel.index,[anio],ventana=cfg.ventana)[0]
        tr,es,ev=fold['tr'],fold['es'],fold['val']
    datos=motor.DatosFold(panel,variables,cfg,tr,secuencial=familia in ('lstm','cnn1d'))
    train,stop,evaluacion=[datos.conjunto_pos(p) for p in [tr,es,ev]]
    assert train.origen.max()+pd.Timedelta(hours=23)<stop.origen.min()
    assert stop.origen.max()+pd.Timedelta(hours=23)<evaluacion.origen.min()
    assert pd.Timestamp(datos.auditoria['fin_ajuste'])<stop.origen.min()
    fabrica=motor.Secuencial
    try:
        if familia=='lstm':motor.Secuencial=Recurrente
        modelo=motor.Entrenador(familia)
        info=modelo.ajustar(train,stop,datos,config['params'],semilla,
                           M.Opciones(max_epocas=60,dispositivo=dispositivo,hilos=2))
    finally:
        motor.Secuencial=fabrica
    pred=datos.invertir(modelo.predecir(evaluacion),evaluacion)
    metricas=evaluar(evaluacion.y,pred,datos.escala_mase)
    if salida is not None:
        destino=Path(salida)/familia/str(semilla)/str(anio if fase=='validacion' else fase)
        destino.mkdir(parents=True,exist_ok=False)
        escala=datos.escaladores()
        torch.save({'state_dict':{k:v.detach().cpu() for k,v in modelo.red.state_dict().items()},
                    'modelo':familia,'params':config['params'],'escaladores':escala},
                    destino/'modelo.pt')
        np.savez_compressed(destino/'predicciones.npz',y=evaluacion.y,yhat=pred,
                            origen=evaluacion.origen.as_unit('ns').asi8)
        for nombre,objeto in [('escaladores',escala),('historia',info['historia']),
                              ('metricas',metricas)]:
            (destino/(nombre+'.json')).write_text(json.dumps(objeto,ensure_ascii=False,
                                                indent=2,default=str),encoding='utf-8')
    return modelo,datos,evaluacion,pred,info,metricas
