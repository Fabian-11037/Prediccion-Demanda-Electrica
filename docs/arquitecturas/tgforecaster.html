10.12. TGForecaster: consultas del horizonte guiadas por texto#

La notación y las operaciones compartidas definen los tensores, el nivel de demanda, la atención, las activaciones y la optimización.

Arquitectura y fundamentos#

TGForecaster utiliza descripciones textuales de los canales para orientar la relación entre información documental y señales numéricas. La atención cruzada distingue qué se pregunta —tokens del horizonte— de dónde se busca la respuesta —la memoria de la historia—. La variante N conserva las descripciones estáticas de canales y no incorpora documentos que cambien por origen; N+O añade el contexto documental oficial disponible.

Cada uno de los 33 canales históricos se divide en 21 parches de 16 horas con paso ocho. Sus embeddings se codifican y se suman a una proyección de la descripción E5 del canal; siete tokens adicionales representan el calendario diario pasado. La memoria reúne así \(33\times21+7=700\) tokens. No se aplica RevIN dentro de este codificador; la normalización externa del contrato permanece.

El horizonte de 24 horas se divide en cinco parches de ocho con paso cuatro. La consulta de cada parche combina descripción de demanda, calendario futuro conocido, posición y resumen de documentos oficiales disponibles en el origen:

\[q_k=W_DE_{dem}+W_FF_k+p_k+m_tW_Tz_t,\quad H=\operatorname{softmax}\!\left(\frac{QK_M^\top}{\sqrt{d_k}}\right)V_M.\]

El texto participa como parte de la consulta; las claves y valores proceden de la memoria numérica. Cada token decodifica ocho correcciones. Para las horas cubiertas por varios parches se aprende una combinación convexa: \(\omega_{k,h}=\operatorname{softmax}_{k:h\in k}(a_{k,h})\), de modo que \(\sum_k\omega_{k,h}=1\). La salida es \(\ell_t[1+\sum_k\omega_{k,h}o_{k,h}]\).

El paquete adapta el artículo a una sola serie objetivo y a documentos disponibles al emitir el pronóstico; no incorpora texto realizado durante el horizonte. Las descripciones y los embeddings son extractores congelados; la selección documental y la fusión son entrenables. La variante N selecciona dimensión256, tres capas temporales, dos de mezcla y ocho cabezas; N+O selecciona dimensión64, dos capas temporales, una de mezcla y cuatro cabezas. Sus configuraciones distintas hacen que el contraste estime el procedimiento completo de selección, además de la incorporación de documentos.

Esquema global#

La historia se divide en parches y se combina con descripciones estáticas de las 33 variables. El calendario pasado completa una memoria de 700 tokens. Cinco consultas incorporan el calendario del horizonte, la descripción de demanda y el resumen documental; la atención cruzada genera parches de pronóstico superpuestos.

Detalle de las operaciones#

La identidad de cada variable se proyecta sobre sus parches históricos. Las consultas del horizonte atienden esa memoria y producen cinco parches de ocho horas, desplazados cuatro horas. Pesos aprendidos, normalizados entre los parches que cubren cada hora, reconstruyen las 24 salidas. La variante numérica conserva las descripciones estáticas y omite los documentos.

El código de exportación de los esquemas forma parte del preprocesamiento compartido.

 17class Relevancia(nn.Module):
 18    """z = V sum_j alfa_j e_j, alfa = softmax_j <K e_j, q> / sqrt(d), sobre los documentos de [origen - 72 h, origen]."""
 19
 20    def __init__(self, vectores: torch.Tensor, lista: torch.Tensor, n_x: int, descripcion: torch.Tensor | None = None):
 21        super().__init__()
 22        self.register_buffer("vectores", vectores, persistent=False)   # (n_docs, 768), congelados
 23        self.register_buffer("lista", lista, persistent=False)         # (n_dias, max_docs), -1 = relleno
 24        d_e = vectores.shape[1]
 25        self.consulta = nn.Sequential(nn.Linear(2 * n_x, D_REL), nn.GELU(), nn.Linear(D_REL, D_REL))
 26        self.clave = nn.Linear(d_e, D_REL, bias=False)
 27        self.valor = nn.Linear(d_e, D_REL, bias=False)
 28        self.desc = None
 29        if descripcion is not None:                                     # descripción fija del canal objetivo (TGForecaster)
 30            self.register_buffer("descripcion", descripcion, persistent=False)
 31            self.desc = nn.Linear(d_e, D_REL, bias=False)
 32
 33    def forward(self, x: torch.Tensor, dia: torch.Tensor):
 34        """x: (B, L, n_x) historia numérica; dia: (B,) día del origen. Devuelve z (B, D_REL), presencia (B,) y pesos."""
 35        q = self.consulta(torch.cat([x[:, -24:].mean(1), x.mean(1)], dim=1))    # solo historia numérica
 36        if self.desc is not None:
 37            q = q + self.desc(self.descripcion)[None, :]
 38        idx = self.lista[dia]                                                    # (B, M): documentos del origen
 39        presente = idx >= 0
 40        e = self.vectores[idx.clamp(min=0)]                                      # (B, M, 768); sin gradiente
 41        puntaje = torch.einsum("bme,be->bm", e, q @ self.clave.weight) / math.sqrt(D_REL)
 42        puntaje = puntaje.masked_fill(~presente, float("-inf"))
 43        hay = presente.any(-1)
 44        alfa = torch.softmax(puntaje.masked_fill(~hay[:, None], 0.0), dim=-1) * presente
 45        hay = hay.to(e.dtype)
 46        z = self.valor(torch.einsum("bm,bme->be", alfa, e)) * hay[:, None]       # cero exacto sin documentos
 47        return z, hay, alfa

 49def _parches(s: torch.Tensor) -> torch.Tensor:
 50    """(N, L) -> (N, 21, PARCHE): se rellena el final con PASO copias del último valor."""
 51    s = torch.cat([s, s[:, -1:].expand(-1, PASO)], dim=1)
 52    return s.unfold(1, PARCHE, PASO)

 54class _CapaPatch(nn.Module):
 55    """Capa de codificador con normalización por lotes, como en PatchTST."""
 56
 57    def __init__(self, d, cabezas, dropout):
 58        super().__init__()
 59        self.atencion = nn.MultiheadAttention(d, cabezas, dropout=dropout, batch_first=True)
 60        self.n1, self.n2 = nn.BatchNorm1d(d), nn.BatchNorm1d(d)
 61        self.ff = nn.Sequential(nn.Linear(d, 2 * d), nn.GELU(), nn.Dropout(dropout), nn.Linear(2 * d, d))
 62        self.drop = nn.Dropout(dropout)
 63
 64    def forward(self, x):
 65        x = x + self.drop(self.atencion(x, x, x, need_weights=False)[0])
 66        x = self.n1(x.transpose(1, 2)).transpose(1, 2)
 67        x = x + self.drop(self.ff(x))
 68        return self.n2(x.transpose(1, 2)).transpose(1, 2)
 69
 70class _CapaMezcla(nn.Module):
 71    """Atención cruzada (consulta: tokens del horizonte; claves y valores: memoria de la serie) y red feed-forward."""
 72
 73    def __init__(self, d, cabezas, dropout):
 74        super().__init__()
 75        self.atencion = nn.MultiheadAttention(d, cabezas, dropout=dropout, batch_first=True)
 76        self.n1, self.n2 = nn.LayerNorm(d), nn.LayerNorm(d)
 77        self.ff = nn.Sequential(nn.Linear(d, 2 * d), nn.GELU(), nn.Dropout(dropout), nn.Linear(2 * d, d))
 78        self.drop = nn.Dropout(dropout)
 79
 80    def forward(self, q, memoria):
 81        q = self.n1(q + self.drop(self.atencion(q, memoria, memoria, need_weights=False)[0]))
 82        return self.n2(q + self.drop(self.ff(q)))

 84class TGForecaster(nn.Module):
 85    """TGForecaster adaptado a un solo objetivo y a texto disponible en el origen.
 86
 87    Del artículo: codificador de parches tipo PatchTST sin normalización reversible, descripciones de canal
 88    codificadas como texto, relevancia de los documentos respecto de la descripción del canal, mezcla por
 89    atención cruzada con el texto como consulta y la serie como claves y valores, consultas alineadas con
 90    el horizonte y decodificador por tokens con suma ponderada.
 91    Adaptaciones: (1) los documentos son los disponibles en [origen - 72 h, origen], no texto del horizonte;
 92    (2) la consulta de cada parche del horizonte suma la descripción de la demanda, el resumen de documentos,
 93    el calendario futuro de ese parche y su posición; (3) la memoria contiene los parches de todas las
 94    variables, identificadas con su descripción, y siete tokens con el calendario diario de la historia,
 95    porque solo se pronostica la demanda y las covariables deben poder informarla.
 96    """
 97
 98    def __init__(self, p: dict, n_x: int, n_cal: int, L: int, H: int, descripciones: torch.Tensor, texto: dict | None = None):
 99        super().__init__()
100        d, capas, cabezas, dropout = int(p["d_model"]), int(p["capas"]), int(p["cabezas"]), float(p["dropout"])
101        if descripciones.shape[0] != n_x:
102            raise ValueError("Debe haber una descripción por canal de la historia")
103        self.register_buffer("descripciones", descripciones, persistent=False)     # (n_x, 768), congeladas; canal 0 = demanda
104        self.n_parches = (L + PASO - PARCHE) // PASO + 1
105        self.dias, self.H = L // 24, H
106        self.emb = nn.Linear(PARCHE, d)
107        self.pos = nn.Parameter(torch.zeros(self.n_parches, d))
108        nn.init.normal_(self.pos, std=0.02)
109        self.capas = nn.ModuleList([_CapaPatch(d, cabezas, dropout) for _ in range(capas)])
110        self.drop = nn.Dropout(dropout)
111        self.proy_desc = nn.Linear(descripciones.shape[1], d)
112        self.cal_dia = nn.Linear(n_cal, d)
113        inicios = torch.arange(0, H - PARCHE_H + 1, PASO_H)
114        self.n_consultas = len(inicios)
115        self.register_buffer("indice_h", inicios[:, None] + torch.arange(PARCHE_H)[None, :], persistent=False)   # (K, PARCHE_H)
116        cubre = torch.zeros(self.n_consultas, H, dtype=torch.bool)
117        cubre.scatter_(1, self.indice_h, True)
118        self.register_buffer("cubre", cubre, persistent=False)
119        self.cal_q = nn.Linear(PARCHE_H * n_cal, d)
120        self.pos_q = nn.Parameter(torch.zeros(self.n_consultas, d))
121        nn.init.normal_(self.pos_q, std=0.02)
122        self.relevancia = None
123        if texto is not None:
124            self.relevancia = Relevancia(texto["vectores"], texto["lista"], n_x, descripciones[0])
125            self.proy_txt = nn.Linear(D_REL, d)
126        self.mezcla = nn.ModuleList([_CapaMezcla(d, cabezas, dropout) for _ in range(int(p["capas_mezcla"]))])
127        self.salida = nn.Linear(d, PARCHE_H)
128        nn.init.zeros_(self.salida.bias)
129        self.peso = nn.Parameter(torch.zeros(self.n_consultas, H))               # suma ponderada de los parches solapados
130
131    def texto_del_origen(self, x, dia):
132        return self.relevancia(x, dia)
133
134    def pesos_horizonte(self) -> torch.Tensor:
135        """(K, H): para cada hora, pesos que suman 1 entre los parches que la cubren."""
136        return torch.softmax(self.peso.masked_fill(~self.cubre, float("-inf")), dim=0)
137
138    def forward(self, x, cal_p, cal_f, dia):
139        B, L, C = x.shape
140        z = self.drop(self.emb(_parches(x.transpose(1, 2).reshape(B * C, L))) + self.pos)
141        for capa in self.capas:
142            z = capa(z)
143        desc = self.proy_desc(self.descripciones)                                              # (C, d)
144        memoria = (z.reshape(B, C, self.n_parches, -1) + desc[None, :, None, :]).reshape(B, C * self.n_parches, -1)
145        dias = self.cal_dia(cal_p.reshape(B, self.dias, L // self.dias, -1).mean(2))           # (B, 7, d)
146        memoria = torch.cat([memoria, dias], dim=1)
147        q = desc[0][None, None, :] + self.cal_q(cal_f[:, self.indice_h].flatten(2)) + self.pos_q   # (B, K, d)
148        if self.relevancia is not None:
149            zt, hay, _ = self.relevancia(x, dia)
150            q = q + (self.proy_txt(zt) * hay[:, None])[:, None, :]                             # cero exacto sin documentos; el sesgo marca presencia
151        q = self.drop(q)
152        for capa in self.mezcla:
153            q = capa(q, memoria)
154        partes = self.salida(q)                                                                # (B, K, PARCHE_H)
155        lienzo = torch.zeros(B, self.n_consultas, self.H, dtype=partes.dtype, device=partes.device)
156        lienzo = lienzo.scatter(2, self.indice_h[None].expand(B, -1, -1), partes)
157        return 1.0 + (lienzo * self.pesos_horizonte()[None]).sum(1)
158
159    def diagnostico(self) -> dict:
160        return {}
161
162    def n_parametros(self) -> int:
163        return sum(v.numel() for v in self.parameters() if v.requires_grad)

python scripts/entrenar_arquitectura.py --modelo tgforecaster --fase prueba --allow-test --semilla 1000 --dispositivo auto --salida salidas/tgforecaster_prueba_1000

El código completo de preparación, optimización, guardado y restauración está en el pipeline ejecutable compartido. Cada salida debe ser una carpeta nueva.

El control numérico con descripciones estáticas se ejecuta con --modelo tgforecaster_n; la variante tgforecaster incorpora los documentos oficiales.

El pipeline fija el plan y las huellas de entrada, genera ventanas cronológicas, ajusta las transformaciones por pliegue y evalúa 20 candidatos en 2018. Confirma cinco finalistas en 2019–2021, selecciona por MASE medio y reajusta con cinco semillas finales usando la reserva interna anterior a 2022. La lectura de la prueba solo ocurre después de cerrar la selección. El libro muestra las implementaciones y no llama al entrenamiento.

121    def ajustar_escalas(self, pos_tr: np.ndarray) -> dict:
122        """Estadísticos estimados solo con las filas de historia de los orígenes de ajuste."""
123        a, b = int(pos_tr.min()) - self.L, int(pos_tr.max())  # filas [a, b): historia de todos los orígenes de ajuste
124        Xa, Ka = self.X[a:b], self.K[a:b]
125        sin_datos = np.isnan(Xa).all(axis=0)
126        with np.errstate(all="ignore"):
127            mediana = np.where(sin_datos, 0.0, np.nanmedian(np.where(sin_datos, 0.0, Xa), axis=0))
128            media = np.where(sin_datos, 0.0, np.nanmean(np.where(sin_datos, 0.0, Xa), axis=0))
129            std = np.where(sin_datos, 1.0, np.nanstd(np.where(sin_datos, 0.0, Xa), axis=0, ddof=1))
130        std = np.where(std > 0, std, 1.0)
131        mc, sc = Ka.mean(axis=0), Ka.std(axis=0, ddof=1)
132        sc = np.where(sc > 0, sc, 1.0)
133        dem = self.X[pos_tr[:, None] + self._off_l, 0]
134        sigma = max(float((dem / dem.mean(axis=1, keepdims=True)).std()), 1e-6)
135        return dict(mediana=mediana, media=media, std=std, media_cal=mc, std_cal=sc, sigma_demanda=sigma,
136                    no_estimables=[c for c, s in zip(self.hist, sin_datos) if s],
137                    inicio_ajuste=str(self.indice[a]), fin_ajuste=str(self.indice[b - 1]), filas_ajuste=int(b - a))
138
139    def construir(self, pos: np.ndarray, esc: dict) -> Conjunto:
140        pos = np.asarray(pos)
141        il, ih = pos[:, None] + self._off_l, pos[:, None] + self._off_h
142        xw = self.X[il]                                    # (n, L, n_hist); solo filas anteriores al origen
143        mascara = self.M[il]
144        xw = np.where(np.isnan(xw), esc["mediana"], xw)
145        nivel = xw[:, :, 0].mean(axis=1)
146        x = (xw - esc["media"]) / esc["std"]
147        x[:, :, 0] = (xw[:, :, 0] / nivel[:, None] - 1.0) / esc["sigma_demanda"]
148        cal_p = (self.K[il] - esc["media_cal"]) / esc["std_cal"]
149        cal_f = (self.K[ih] - esc["media_cal"]) / esc["std_cal"]
150        return Conjunto(np.concatenate([x, mascara], axis=2).astype("float32"), cal_p.astype("float32"), cal_f.astype("float32"),
151                        self.Y[ih], nivel, self.indice[pos], self.dia_de(pos))
152
153    # ---------------------------------------------------------------- referencias
154    def ingenuos(self, pos: np.ndarray) -> dict[str, np.ndarray]:
155        """Ingenuos diario y semanal con la misma disponibilidad que los modelos (kWh)."""
156        lag = C.REZAGO_H["demanda_real"]
157        out = {}
158        for nombre, base in (("ingenuo_24h", 24), ("ingenuo_168h", 168)):
159            pred = np.zeros((len(pos), self.H))
160            for h in range(self.H):
161                k = int(np.ceil((h + 1 + lag) / base)) if base == 24 else 1
162                pred[:, h] = self.Y[pos + h - base * max(k, 1)]
163            out[nombre] = pred
164        return out

166    def mase_por_origen(self, y: np.ndarray, yhat: np.ndarray) -> np.ndarray:
167        return np.abs(y - yhat).mean(axis=1) / self.q168

 40@torch.no_grad()
 41def predecir(red, t: dict, lote: int = 256) -> np.ndarray:
 42    """Predicción normalizada (demanda / nivel) en modo evaluación."""
 43    red.eval()
 44    n = len(t["y"])
 45    partes = [_salida(red, t, slice(i, i + lote)).float().cpu().numpy() for i in range(0, n, lote)]
 46    return np.concatenate(partes, axis=0)

 49@torch.no_grad()
 50def _perdida(red, t: dict, lote: int = 256) -> float:
 51    red.eval()
 52    n, tot = len(t["y"]), 0.0
 53    for i in range(0, n, lote):
 54        s = slice(i, i + lote)
 55        tot += float((_salida(red, t, s) - t["y"][s]).abs().mean()) * len(t["y"][s])
 56    return tot / n

 59def entrenar(red, tr: dict, es: dict, p: dict, semilla: int, opciones: dict, observador=None) -> dict:
 60    """Ajusta ``red`` con ``tr`` y detiene con ``es``. Devuelve la historia y deja en ``red`` el mejor estado."""
 61    dev = tr["x"].device
 62    perdida = nn.L1Loss()
 63    opt = torch.optim.AdamW(red.parameters(), lr=float(p["lr"]), weight_decay=float(p["weight_decay"]))
 64    plan = torch.optim.lr_scheduler.ReduceLROnPlateau(opt, factor=0.5, patience=2)
 65    mejor = referencia = float("inf")
 66    estado, sin_mejora, historia = None, 0, []
 67    gen = torch.Generator().manual_seed(int(semilla))
 68    lote, n = int(p["lote"]), len(tr["y"])
 69    t0 = time.time()
 70    for ep in range(1, int(opciones["max_epocas"]) + 1):
 71        red.train()
 72        tot = 0.0
 73        for ix in torch.randperm(n, generator=gen).split(lote):
 74            if len(ix) < 2:      # la normalización por lotes necesita más de una muestra
 75                continue
 76            ix = ix.to(dev)
 77            opt.zero_grad(set_to_none=True)
 78            loss = perdida(_salida(red, tr, ix), tr["y"][ix])
 79            if not torch.isfinite(loss):
 80                raise FloatingPointError("Pérdida no finita")
 81            loss.backward()
 82            nn.utils.clip_grad_norm_(red.parameters(), float(opciones["recorte_gradiente"]))
 83            opt.step()
 84            tot += float(loss.detach()) * len(ix)
 85        vl = _perdida(red, es)
 86        historia.append(dict(epoca=ep, perdida_ajuste=tot / n, perdida_parada=vl, lr=opt.param_groups[0]["lr"], segundos=round(time.time() - t0, 1)))
 87        if vl < mejor:
 88            mejor = vl
 89            estado = {k: v.detach().clone() for k, v in red.state_dict().items()}
 90        if not np.isfinite(referencia) or vl < referencia - max(1e-6, 0.002 * abs(referencia)):
 91            referencia, sin_mejora = vl, 0
 92        else:
 93            sin_mejora += 1
 94        plan.step(vl)
 95        if observador is not None:
 96            observador(historia[-1])
 97        if ep >= int(opciones["min_epocas"]) and sin_mejora >= int(opciones["paciencia"]):
 98            break
 99    red.load_state_dict(estado)
100    return dict(epocas=len(historia), mejor_epoca=int(np.argmin([h["perdida_parada"] for h in historia]) + 1),
101                mejor_perdida_parada=float(mejor), historia=historia, segundos=round(time.time() - t0, 1))

191def bootstrap_bloques(dif: np.ndarray, base: np.ndarray, bloque: int, remuestreos: int, semilla: int) -> dict:
192    """Bootstrap circular por bloques de días para la diferencia pareada por origen (A - B) y su valor relativo a B."""
193    n = len(dif)
194    g = np.random.default_rng(semilla)
195    nb = int(np.ceil(n / bloque))
196    d_obs, b_obs = float(dif.mean()), float(base.mean())
197    md, mb = np.empty(remuestreos), np.empty(remuestreos)
198    for a in range(0, remuestreos, 500):
199        k = min(500, remuestreos - a)
200        ix = ((g.integers(0, n, size=(k, nb))[:, :, None] + np.arange(bloque)[None, None, :]) % n).reshape(k, -1)[:, :n]
201        md[a:a + k], mb[a:a + k] = dif[ix].mean(axis=1), base[ix].mean(axis=1)
202    rel = 100 * md / mb
203    return dict(bloque_dias=int(bloque), remuestreos=int(remuestreos), diferencia_MASE=d_obs, ic95_diferencia_MASE=[float(v) for v in np.percentile(md, [2.5, 97.5])],
204                diferencia_relativa_pct=100 * d_obs / b_obs, ic95_diferencia_relativa_pct=[float(v) for v in np.percentile(rel, [2.5, 97.5])],
205                p_bilateral_bootstrap=float((np.abs(md - d_obs) >= abs(d_obs)).mean()))

 39def listas_por_dia(disponible: pd.Series, dia_base: pd.Timestamp, n_dias: int, ventana_h: int, max_n: int):
 40    """Para cada día d (00:00 de Bogotá) devuelve los documentos con disponibilidad en [d - ventana, d].
 41
 42    Misma regla que ``demanda.corpus.documentos_en_origen``: extremos inclusivos y, si hay más de
 43    ``max_n``, se conservan los más recientes. Devuelve (lista, total_en_ventana): ``lista`` es
 44    (n_dias, max_n) con posiciones del corpus y -1 como relleno.
 45    """
 46    valores = pd.DatetimeIndex(disponible).as_unit("ns").asi8
 47    dias = pd.DatetimeIndex([dia_base + pd.Timedelta(days=i) for i in range(n_dias)]).tz_convert("UTC").as_unit("ns").asi8
 48    hi = np.searchsorted(valores, dias, side="right")
 49    lo = np.searchsorted(valores, dias - int(ventana_h) * 3600 * 10**9, side="left")
 50    total = hi - lo
 51    lo2 = np.maximum(lo, hi - max_n)
 52    lista = np.full((n_dias, max_n), -1, dtype="int64")
 53    for i in range(n_dias):
 54        k = hi[i] - lo2[i]
 55        if k:
 56            lista[i, :k] = np.arange(lo2[i], hi[i])
 57    return lista, total

 61def fragmentar(ids: list[int], capacidad: int, solape: int, max_frag: int):
 62    """Fragmentos en orden de lectura. Devuelve (fragmentos conservados, número total de fragmentos)."""
 63    if len(ids) <= capacidad:
 64        return [ids], 1
 65    paso = capacidad - solape
 66    inicios = list(range(0, len(ids) - solape, paso))
 67    return [ids[i:i + capacidad] for i in inicios[:max_frag]], len(inicios)

 79def vectores_de_prueba(corpus: pd.DataFrame) -> np.ndarray:
 80    """Vectores seudoaleatorios deterministas por documento. SOLO para verificar la instalación."""
 81    out = np.empty((len(corpus), DIM), dtype="float32")
 82    for i, s in enumerate(corpus["sha_contenido"]):
 83        g = np.random.default_rng(int(s[:16], 16))
 84        v = g.standard_normal(DIM).astype("float32")
 85        out[i] = v / np.linalg.norm(v)
 86    return out

109def codificar(corpus: pd.DataFrame, cfg_texto: dict, carpeta: Path, dispositivo: str, log, codificador: str | None = None,
110              limite: int | None = None, barra=None, vecinos: Path | None = None) -> dict:
111    """Calcula (o reanuda) los vectores por documento y los guarda en ``carpeta``.
112
113    ``codificador`` permite una ruta local; por defecto se descarga el modelo fijado en el contrato.
114    ``limite`` codifica solo los primeros documentos (verificación de instalación).
115    """
116    import torch
117    import transformers
118    from transformers import AutoModel, AutoTokenizer
119
120    transformers.logging.set_verbosity_error()   # el aviso de "más de 512 tokens" no aplica: aquí se fragmenta
121    try:
122        transformers.utils.logging.disable_progress_bar()   # la barra de carga de pesos se mezclaría con la de avance
123    except Exception:
124        pass
125
126    carpeta = Path(carpeta); carpeta.mkdir(parents=True, exist_ok=True)
127    nombre = codificador or cfg_texto["encoder"]
128    es_local = Path(nombre).exists()
129    ficha = _ficha(cfg_texto, corpus, nombre)
130    rf, rv, ri, rp = carpeta / "ficha.json", carpeta / "vectores_documento.npy", carpeta / "indice.parquet", carpeta / "parcial.npz"
131    if limite is None and rf.exists() and rv.exists() and json.loads(rf.read_text(encoding="utf-8")).get("ficha") == ficha:
132        log("Vectores de texto ya calculados; se reutilizan.")
133        return json.loads(rf.read_text(encoding="utf-8"))
134    if limite is None and not rp.exists():
135        r = _copiar_de_vecino(vecinos, carpeta, ficha, log)
136        if r is not None:
137            if barra is not None:
138                barra.update(len(corpus))
139            return r
140
141    log(f"Cargando el codificador de texto {nombre} (la primera vez descarga cerca de 1 GB)...")
142    kw = {} if es_local else {"revision": cfg_texto["revision"]}
143    try:
144        tok = AutoTokenizer.from_pretrained(nombre, **kw)
145        modelo = AutoModel.from_pretrained(nombre, **kw).to(dispositivo).eval()
146    except Exception as e:
147        raise RuntimeError(f"No se pudo cargar el codificador de texto {nombre} (revisión {cfg_texto['revision']}). Revise la conexión a internet y vuelva a "
148                           f"ejecutar. Si el mensaje original dice que la revisión o el modelo no existen, avise al autor del paquete. Mensaje original: {e}") from e
149    dim = int(modelo.config.hidden_size)
150    ids_prefijo = tok(cfg_texto["prefijo"], add_special_tokens=False)["input_ids"]
151    # Tokens especiales de una secuencia simple, deducidos del propio tokenizador (válido en transformers 4 y 5).
152    completo = tok(cfg_texto["prefijo"], add_special_tokens=True)["input_ids"]
153    k = next(i for i in range(len(completo) - len(ids_prefijo) + 1) if completo[i:i + len(ids_prefijo)] == ids_prefijo)
154    inicio, cierre = completo[:k], completo[k + len(ids_prefijo):]
155    capacidad = int(cfg_texto["tokens_max"]) - len(inicio) - len(cierre) - len(ids_prefijo)
156    solape, max_frag = int(cfg_texto["solapamiento_tokens"]), int(cfg_texto["max_fragmentos_documento"])
157    n = len(corpus) if limite is None else min(limite, len(corpus))
158
159    vec = np.zeros((n, dim), dtype="float32")
160    meta = np.zeros((n, 3), dtype="int64")  # tokens, fragmentos totales, fragmentos usados
161    hecho = 0
162    if limite is None and rp.exists():
163        z = np.load(rp, allow_pickle=False)
164        if str(z["sha"]) == ficha["sha256_contenidos"] and z["vec"].shape[1] == dim:
165            hecho = int(z["hecho"]); vec[:hecho] = z["vec"][:hecho]; meta[:hecho] = z["meta"][:hecho]
166            log(f"Se reanuda la codificación desde el documento {hecho} de {n}.")
167    lote = 32 if dispositivo != "cpu" else 8
168    bloque = 256
169    t0 = time.time()
170    for a in range(hecho, n, bloque):
171        b = min(a + bloque, n)
172        frags, dueno = [], []
173        for i in range(a, b):
174            ids = tok(contenido(corpus.iloc[i]), add_special_tokens=False)["input_ids"]
175            fr, total = fragmentar(ids, capacidad, solape, max_frag)
176            meta[i] = (len(ids), total, len(fr))
177            for f in fr:
178                frags.append(inicio + ids_prefijo + f + cierre); dueno.append(i - a)
179        orden = np.argsort([len(f) for f in frags])
180        emb = np.zeros((len(frags), dim), dtype="float32")
181        for j in range(0, len(orden), lote):
182            sel = orden[j:j + lote]
183            largo = max(len(frags[k]) for k in sel)
184            ids_t = torch.full((len(sel), largo), tok.pad_token_id, dtype=torch.long)
185            att = torch.zeros((len(sel), largo), dtype=torch.long)
186            for r, k in enumerate(sel):
187                ids_t[r, :len(frags[k])] = torch.tensor(frags[k]); att[r, :len(frags[k])] = 1
188            ids_t, att = ids_t.to(dispositivo), att.to(dispositivo)
189            with torch.no_grad():                                  # precisión simple, sin autocast
190                h = modelo(input_ids=ids_t, attention_mask=att).last_hidden_state.float()
191            m = att.unsqueeze(-1).float()
192            v = (h * m).sum(1) / m.sum(1).clamp(min=1.0)          # promedio de tokens con máscara
193            v = torch.nn.functional.normalize(v, dim=-1)           # L2 por fragmento
194            emb[sel] = v.cpu().numpy()
195        dueno = np.asarray(dueno)
196        for i in range(a, b):
197            d = emb[dueno == (i - a)].mean(axis=0)
198            vec[i] = d / max(float(np.linalg.norm(d)), 1e-12)       # vector del documento: promedio de fragmentos, L2
199        if barra is not None:
200            barra.update(b - a)
201        if limite is None and (b == n or (b // bloque) % 4 == 0):
202            np.savez(rp, vec=vec, meta=meta, hecho=b, sha=ficha["sha256_contenidos"])
203    del modelo
204    if dispositivo.startswith("cuda"):
205        torch.cuda.empty_cache()
206    resumen = dict(ficha=ficha, dimension=dim, documentos_codificados=int(n), segundos=round(time.time() - t0, 1), dispositivo=dispositivo,
207                   documentos_truncados=int((meta[:n, 1] > meta[:n, 2]).sum()),
208                   porcentaje_documentos_truncados=round(100 * float((meta[:n, 1] > meta[:n, 2]).mean()), 2),
209                   porcentaje_tokens_descartados=round(100 * float(1 - np.minimum(meta[:n, 0], meta[:n, 2] * capacidad).sum() / max(meta[:n, 0].sum(), 1)), 2),
210                   capacidad_tokens_por_fragmento=int(capacidad), tokens_especiales=[len(inicio), len(cierre)], tokens_prefijo=len(ids_prefijo),
211                   transformers=transformers.__version__, codificador_de_prueba=False)
212    if limite is None:
213        np.save(rv, vec.astype("float16"))
214        pd.DataFrame(dict(id=corpus["id"].to_numpy()[:n], fuente=corpus["fuente"].to_numpy()[:n], sha_contenido=corpus["sha_contenido"].to_numpy()[:n],
215                          tokens=meta[:n, 0], fragmentos_totales=meta[:n, 1], fragmentos_usados=meta[:n, 2])).to_parquet(ri, index=False)
216        rf.write_text(json.dumps(resumen, ensure_ascii=False, indent=1), encoding="utf-8")
217        if rp.exists():
218            rp.unlink()
219    return resumen
