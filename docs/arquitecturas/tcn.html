10.9. TCN: convoluciones causales dilatadas#

La notación y las operaciones compartidas definen los tensores, el nivel de demanda, la atención, las activaciones y la optimización.

Arquitectura y fundamentos#

Una TCN aumenta su alcance temporal separando las posiciones que consulta cada filtro. Con dilatación cuatro, por ejemplo, un núcleo de cinco pesos lee posiciones separadas cuatro horas. El apilamiento permite integrar semanas de historia sin usar recurrencia. La causalidad se impone recortando el relleno derecho de cada convolución.

La red seleccionada usa tres bloques de 64 filtros, dilataciones 1, 4 y 16 y núcleo cinco. Cada bloque contiene dos convoluciones, normalización de pesos, ReLU y una conexión residual; una proyección \(1\times1\) adapta el atajo si cambia el número de canales. El dropout de 0,2 está activo al final del bloque central, de acuerdo con el patrón (0,1,0).

\[\operatorname{Conv}_{d}(x)_s=\sum_{i=0}^{k-1}W_i x_{s-di}+b,\qquad h_{b+1}=\operatorname{ReLU}(S_bh_b+F_b(h_b)).\]

Con dos convoluciones por bloque, el campo receptivo es \(R=1+2(k-1)\sum_bd_b=169\) horas, suficiente para las 168 de entrada. El resultado depende de contar ambas convoluciones: una sola por bloque no cubriría la ventana. La representación de la última hora se concatena con una proyección del calendario futuro y una cabeza densa produce las 24 correcciones normalizadas. Hay 169.944 parámetros.

La implementación utiliza únicamente datos anteriores al origen en las convoluciones. El calendario futuro entra por una rama separada porque sí se conoce de antemano. Los 20 candidatos efectivamente evaluados no equivalen a completar el espacio de 1.000 arquitecturas exigido por la pauta cuando no existe una configuración publicada adoptada.

Esquema global#

Los 56 canales históricos atraviesan tres bloques causales con dilataciones 1, 4 y 16. Su campo receptivo de 169 horas cubre la ventana de 168 horas; el último estado se combina con el calendario futuro para producir las 24 salidas.

Detalle de las operaciones#

Cada bloque contiene dos convoluciones de cinco posiciones, recorte del relleno derecho y una conexión residual. El bloque central aplica dropout de 0,2; el atajo proyecta los canales cuando cambia su dimensión. La lectura combina 64 atributos temporales y 64 de calendario.

El código de exportación de los esquemas forma parte del preprocesamiento compartido.

19def campo_receptivo_tcn(kernel: int) -> int:
20    """Dos convoluciones causales por bloque: R = 1 + 2 (k - 1) (1 + 4 + 16)."""
21    return 1 + 2 * (int(kernel) - 1) * sum(DILATACIONES_TCN)
22
23class _BloqueTCN(nn.Module):
24    """Bloque residual de Bai et al. (2018): dos convoluciones causales dilatadas con normalización de pesos."""
25
26    def __init__(self, c_in: int, c_out: int, kernel: int, dilatacion: int, dropout: float):
27        super().__init__()
28        self.recorte = (kernel - 1) * dilatacion
29        convs = [nn.Conv1d(c_in, c_out, kernel, padding=self.recorte, dilation=dilatacion), nn.Conv1d(c_out, c_out, kernel, padding=self.recorte, dilation=dilatacion)]
30        for c in convs:
31            nn.init.normal_(c.weight, 0.0, 0.01)
32        self.c1, self.c2 = (nn.utils.parametrizations.weight_norm(c) for c in convs)
33        self.drop = nn.Dropout(dropout) if dropout > 0 else nn.Identity()       # al final del bloque
34        self.atajo = nn.Conv1d(c_in, c_out, 1) if c_in != c_out else None
35
36    def forward(self, x):
37        y = torch.relu(self.c1(x)[..., :-self.recorte])       # el recorte quita el relleno derecho: no se mira adelante
38        y = self.drop(torch.relu(self.c2(y)[..., :-self.recorte]))
39        return torch.relu(y + (x if self.atajo is None else self.atajo(x)))

41class TCN(nn.Module):
42    """TCN de tres bloques con dilataciones (1, 4, 16) y cabeza con el calendario futuro conocido.
43
44    Entrada de las convoluciones: variables históricas, indicadores de ausencia y calendario de la historia.
45    Se toma la representación de la última hora de la historia, se une con una proyección del calendario
46    futuro y una cabeza densa produce las 24 horas (misma convención que las redes base del proyecto).
47    """
48
49    def __init__(self, p: dict, n_x: int, n_cal: int, L: int, H: int):
50        super().__init__()
51        anchos, patron, k, tasa = [int(a) for a in p["anchos"]], [int(b) for b in p["patron_dropout"]], int(p["kernel"]), float(p["dropout"])
52        if len(anchos) != 3 or len(patron) != 3:
53            raise ValueError("TCN usa tres bloques")
54        if campo_receptivo_tcn(k) < L:
55            raise ValueError(f"El campo receptivo ({campo_receptivo_tcn(k)}) no cubre la historia ({L})")
56        canales = [n_x + n_cal] + anchos
57        self.bloques = nn.ModuleList([_BloqueTCN(canales[i], canales[i + 1], k, DILATACIONES_TCN[i], tasa if patron[i] else 0.0) for i in range(3)])
58        w = anchos[-1]
59        self.cal = nn.Linear(H * n_cal, w)
60        self.cabeza = nn.Sequential(nn.Linear(2 * w, w), nn.ReLU(), nn.Linear(w, H))
61        nn.init.zeros_(self.cabeza[-1].bias)
62
63    def forward(self, x, cal_p, cal_f, dia):
64        s = torch.cat([x, cal_p], dim=2).transpose(1, 2)        # (B, canales, L)
65        for bloque in self.bloques:
66            s = bloque(s)
67        z = torch.cat([s[:, :, -1], torch.relu(self.cal(cal_f.flatten(1)))], dim=1)
68        return 1.0 + self.cabeza(z)
69
70    def diagnostico(self) -> dict:
71        return {}
72
73    def n_parametros(self) -> int:
74        return sum(v.numel() for v in self.parameters() if v.requires_grad)

Pipeline de entrenamiento y prueba#

El pipeline fija el plan y las huellas de entrada, genera ventanas cronológicas, ajusta las transformaciones por pliegue y evalúa 20 candidatos en 2018. Confirma cinco finalistas en 2019–2021, selecciona por MASE medio y reajusta con cinco semillas finales usando la reserva interna anterior a 2022. La lectura de la prueba solo ocurre después de cerrar la selección. El libro muestra las implementaciones y no llama al entrenamiento.

 59def entrenar(red, tr: dict, es: dict, p: dict, semilla: int, opciones: dict, observador=None) -> dict:
 60    """Ajusta ``red`` con ``tr`` y detiene con ``es``. Devuelve la historia y deja en ``red`` el mejor estado."""
 61    dev = tr["x"].device
 62    perdida = nn.L1Loss()
 63    opt = torch.optim.AdamW(red.parameters(), lr=float(p["lr"]), weight_decay=float(p["weight_decay"]))
 64    plan = torch.optim.lr_scheduler.ReduceLROnPlateau(opt, factor=0.5, patience=2)
 65    mejor = referencia = float("inf")
 66    estado, sin_mejora, historia = None, 0, []
 67    gen = torch.Generator().manual_seed(int(semilla))
 68    lote, n = int(p["lote"]), len(tr["y"])
 69    t0 = time.time()
 70    for ep in range(1, int(opciones["max_epocas"]) + 1):
 71        red.train()
 72        tot = 0.0
 73        for ix in torch.randperm(n, generator=gen).split(lote):
 74            if len(ix) < 2:      # la normalización por lotes necesita más de una muestra
 75                continue
 76            ix = ix.to(dev)
 77            opt.zero_grad(set_to_none=True)
 78            loss = perdida(_salida(red, tr, ix), tr["y"][ix])
 79            if not torch.isfinite(loss):
 80                raise FloatingPointError("Pérdida no finita")
 81            loss.backward()
 82            nn.utils.clip_grad_norm_(red.parameters(), float(opciones["recorte_gradiente"]))
 83            opt.step()
 84            tot += float(loss.detach()) * len(ix)
 85        vl = _perdida(red, es)
 86        historia.append(dict(epoca=ep, perdida_ajuste=tot / n, perdida_parada=vl, lr=opt.param_groups[0]["lr"], segundos=round(time.time() - t0, 1)))
 87        if vl < mejor:
 88            mejor = vl
 89            estado = {k: v.detach().clone() for k, v in red.state_dict().items()}
 90        if not np.isfinite(referencia) or vl < referencia - max(1e-6, 0.002 * abs(referencia)):
 91            referencia, sin_mejora = vl, 0
 92        else:
 93            sin_mejora += 1
 94        plan.step(vl)
 95        if observador is not None:
 96            observador(historia[-1])
 97        if ep >= int(opciones["min_epocas"]) and sin_mejora >= int(opciones["paciencia"]):
 98            break
 99    red.load_state_dict(estado)
100    return dict(epocas=len(historia), mejor_epoca=int(np.argmin([h["perdida_parada"] for h in historia]) + 1),
101                mejor_perdida_parada=float(mejor), historia=historia, segundos=round(time.time() - t0, 1))

191def bootstrap_bloques(dif: np.ndarray, base: np.ndarray, bloque: int, remuestreos: int, semilla: int) -> dict:
192    """Bootstrap circular por bloques de días para la diferencia pareada por origen (A - B) y su valor relativo a B."""
193    n = len(dif)
194    g = np.random.default_rng(semilla)
195    nb = int(np.ceil(n / bloque))
196    d_obs, b_obs = float(dif.mean()), float(base.mean())
197    md, mb = np.empty(remuestreos), np.empty(remuestreos)
198    for a in range(0, remuestreos, 500):
199        k = min(500, remuestreos - a)
200        ix = ((g.integers(0, n, size=(k, nb))[:, :, None] + np.arange(bloque)[None, None, :]) % n).reshape(k, -1)[:, :n]
201        md[a:a + k], mb[a:a + k] = dif[ix].mean(axis=1), base[ix].mean(axis=1)
202    rel = 100 * md / mb
203    return dict(bloque_dias=int(bloque), remuestreos=int(remuestreos), diferencia_MASE=d_obs, ic95_diferencia_MASE=[float(v) for v in np.percentile(md, [2.5, 97.5])],
204                diferencia_relativa_pct=100 * d_obs / b_obs, ic95_diferencia_relativa_pct=[float(v) for v in np.percentile(rel, [2.5, 97.5])],
205                p_bilateral_bootstrap=float((np.abs(md - d_obs) >= abs(d_obs)).mean()))

 90    """Dos archivos para enviar: resultados (liviano) y pesos + vectores de texto (pesado)."""
 91    sello = dt.datetime.now().strftime("%Y%m%d_%H%M")
 92    pesados = lambda r: r.name in ("modelo.pt", "vectores_documento.npy", "parcial.npz")   # noqa: E731

 95        with zipfile.ZipFile(destino, "w", nivel) as z:
 96            for r in sorted(salida.rglob("*")):
 97                if r.is_file() and criterio(r):
 98                    z.write(r, Path(salida.name) / r.relative_to(salida))
