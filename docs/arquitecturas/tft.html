10.8. TFT: selección de variables y atención interpretable#

La notación y las operaciones compartidas definen los tensores, el nivel de demanda, la atención, las activaciones y la optimización.

Arquitectura y fundamentos#

TFT combina selección de variables, memoria recurrente y atención. Primero decide qué variables ponderar en cada hora; después resume la secuencia y permite que cada hora del horizonte consulte los pasos relevantes de la historia. Las compuertas residuales regulan cuánto de cada transformación se incorpora.

La configuración seleccionada tiene ancho 160 y cuatro cabezas. Recibe 56 variables pasadas: 30 históricas, tres indicadores de ausencia por bloque y 23 de calendario. El futuro contiene únicamente 23 variables de calendario. Cada variable continua tiene un embedding lineal y una GRN propia. Una segunda GRN produce pesos softmax \(v_{s,j}\); su suma es uno y la representación seleccionada es \(z_s=\sum_jv_{s,j}\operatorname{GRN}_j(e_{s,j})\).

Una GRN utiliza una transformación no lineal, una compuerta y un atajo:

\[\operatorname{GRN}(a)=\operatorname{LayerNorm}\!\left(Sa+\operatorname{GLU}(W_1\operatorname{ELU}(W_2a+b_2)+b_1)\right),\quad \operatorname{GLU}(u)=\sigma(W_gu+b_g)\odot(W_vu+b_v).\]

El codificador LSTM procesa las 168 horas y su estado inicializa al decodificador que recibe el calendario futuro. El enriquecimiento GRN precede a la atención interpretable: las cabezas comparten la proyección de valores y se promedian. La máscara impide que la consulta de la hora \(h\) utilice representaciones del decodificador posteriores a ella. Las GRN por posición y las compuertas finales producen una salida escalar por hora. El total es de 11.715.596 parámetros.

Se omiten codificadores estáticos porque se estudia una sola serie. Se entrena un pronóstico puntual con MAE normalizado, no todos los cuantiles del artículo. Los pesos de selección describen el mecanismo del modelo; no son efectos causales de las variables. Esta documentación y los resultados usan la configuración TFT seleccionada del paquete, identificada por sus fuentes y checkpoints.

Esquema global#

La selección de variables transforma las 56 entradas históricas y las 23 de calendario futuro a representaciones de dimensión 160. La recurrencia, las compuertas y la atención de cuatro cabezas producen una salida por hora.

Detalle de las operaciones#

Las GRN combinan transformaciones no lineales con conexiones residuales y compuertas. La selección softmax pondera las representaciones de las variables en cada instante; esos pesos describen el mecanismo interno y no efectos causales.

El código de exportación de los esquemas forma parte del preprocesamiento compartido.

 19class _GLU(nn.Module):
 20    """Compuerta lineal: sigmoide(W4 g + b4) * (W5 g + b5)."""
 21
 22    def __init__(self, d_in: int, d_out: int):
 23        super().__init__()
 24        self.lineal = nn.Linear(d_in, 2 * d_out)
 25
 26    def forward(self, g):
 27        a, b = self.lineal(g).chunk(2, dim=-1)
 28        return torch.sigmoid(a) * b
 29
 30class _CompuertaSuma(nn.Module):
 31    """LayerNorm(atajo + GLU(dropout(x)))."""
 32
 33    def __init__(self, d: int, dropout: float):
 34        super().__init__()
 35        self.drop, self.glu, self.norma = nn.Dropout(dropout), _GLU(d, d), nn.LayerNorm(d)
 36
 37    def forward(self, x, atajo):
 38        return self.norma(atajo + self.glu(self.drop(x)))
 39
 40class _GRN(nn.Module):
 41    """Red residual con compuerta del TFT: LayerNorm(a + GLU(W1 ELU(W2 a + b2) + b1))."""
 42
 43    def __init__(self, d_in: int, d: int, d_out: int, dropout: float):
 44        super().__init__()
 45        self.fc2, self.fc1 = nn.Linear(d_in, d), nn.Linear(d, d)
 46        self.atajo = nn.Linear(d_in, d_out) if d_in != d_out else None
 47        self.drop, self.glu, self.norma = nn.Dropout(dropout), _GLU(d, d_out), nn.LayerNorm(d_out)
 48
 49    def forward(self, a):
 50        h = self.fc1(torch.nn.functional.elu(self.fc2(a)))
 51        return self.norma((a if self.atajo is None else self.atajo(a)) + self.glu(self.drop(h)))
 52
 53class _SeleccionVariables(nn.Module):
 54    """Red de selección de variables: una GRN por variable y pesos softmax por paso de tiempo.
 55
 56    Las GRN por variable se calculan en paralelo con pesos apilados (V, d, d); equivale a V redes separadas.
 57    """
 58
 59    def __init__(self, n_var: int, d: int, dropout: float):
 60        super().__init__()
 61        self.n_var, self.d = n_var, d
 62        self.w_emb, self.b_emb = nn.Parameter(torch.empty(n_var, d)), nn.Parameter(torch.zeros(n_var, d))     # embedding lineal de cada variable continua
 63        nn.init.normal_(self.w_emb, std=1.0 / math.sqrt(d))
 64        self.w2, self.b2 = nn.Parameter(torch.empty(n_var, d, d)), nn.Parameter(torch.zeros(n_var, d))
 65        self.w1, self.b1 = nn.Parameter(torch.empty(n_var, d, d)), nn.Parameter(torch.zeros(n_var, d))
 66        self.wg, self.bg = nn.Parameter(torch.empty(n_var, d, 2 * d)), nn.Parameter(torch.zeros(n_var, 2 * d))
 67        for w in (self.w2, self.w1, self.wg):
 68            nn.init.uniform_(w, -1.0 / math.sqrt(d), 1.0 / math.sqrt(d))
 69        self.ganancia, self.sesgo = nn.Parameter(torch.ones(n_var, d)), nn.Parameter(torch.zeros(n_var, d))
 70        self.drop = nn.Dropout(dropout)
 71        self.pesos = _GRN(n_var * d, d, n_var, dropout)
 72
 73    def forward(self, x):
 74        """x: (B, T, V) -> (B, T, d) y pesos de selección (B, T, V)."""
 75        xi = x.unsqueeze(-1) * self.w_emb + self.b_emb                                   # (B, T, V, d)
 76        v = torch.softmax(self.pesos(xi.flatten(2)), dim=-1)                             # (B, T, V)
 77        h = torch.nn.functional.elu(torch.einsum("btvd,vde->btve", xi, self.w2) + self.b2)
 78        h = self.drop(torch.einsum("btvd,vde->btve", h, self.w1) + self.b1)
 79        a, b = (torch.einsum("btvd,vde->btve", h, self.wg) + self.bg).chunk(2, dim=-1)
 80        z = torch.nn.functional.layer_norm(xi + torch.sigmoid(a) * b, (self.d,)) * self.ganancia + self.sesgo
 81        return (v.unsqueeze(-1) * z).sum(2), v
 82
 83class _AtencionInterpretable(nn.Module):
 84    """Atención multicabeza interpretable: las cabezas comparten los valores y se promedian sus salidas."""
 85
 86    def __init__(self, d: int, cabezas: int, dropout: float):
 87        super().__init__()
 88        if d % cabezas:
 89            raise ValueError("El tamaño oculto debe ser divisible entre el número de cabezas")
 90        self.h, self.dk = cabezas, d // cabezas
 91        self.q, self.k = nn.Linear(d, d, bias=False), nn.Linear(d, d, bias=False)
 92        self.v = nn.Linear(d, self.dk, bias=False)                  # valores compartidos por todas las cabezas
 93        self.salida = nn.Linear(self.dk, d, bias=False)
 94        self.drop = nn.Dropout(dropout)
 95
 96    def forward(self, consulta, memoria, mascara):
 97        B, Tq, _ = consulta.shape
 98        q = self.q(consulta).view(B, Tq, self.h, self.dk).transpose(1, 2)               # (B, h, Tq, dk)
 99        k = self.k(memoria).view(B, -1, self.h, self.dk).transpose(1, 2)                # (B, h, Tk, dk)
100        a = (q @ k.transpose(-1, -2)) / math.sqrt(self.dk)
101        a = self.drop(torch.softmax(a.masked_fill(~mascara, float("-inf")), dim=-1))    # (B, h, Tq, Tk)
102        return self.salida(a.mean(1) @ self.v(memoria))
103
104class TFT(nn.Module):
105    """Temporal Fusion Transformer (Lim et al., 2021, arXiv:1912.09363) para una serie y pronóstico puntual.
106
107    Entradas pasadas: variables históricas, indicadores de ausencia y calendario de la historia (168 h).
108    Entradas futuras conocidas: calendario de las 24 h del horizonte.
109    Componentes del artículo: selección de variables, codificador y decodificador LSTM, compuertas con
110    suma y normalización, enriquecimiento con GRN, atención multicabeza interpretable con máscara causal
111    y GRN por posición. No hay covariables estáticas (una sola serie), así que se omiten sus codificadores.
112    """
113
114    def __init__(self, p: dict, n_x: int, n_cal: int, L: int, H: int):
115        super().__init__()
116        d, cabezas, dropout = int(p["d_model"]), int(p["cabezas"]), float(p["dropout"])
117        self.L, self.H = L, H
118        self.sel_pasado = _SeleccionVariables(n_x + n_cal, d, dropout)
119        self.sel_futuro = _SeleccionVariables(n_cal, d, dropout)
120        self.codificador, self.decodificador = nn.LSTM(d, d, batch_first=True), nn.LSTM(d, d, batch_first=True)
121        self.puerta_lstm = _CompuertaSuma(d, dropout)
122        self.enriquecimiento = _GRN(d, d, d, dropout)
123        self.atencion = _AtencionInterpretable(d, cabezas, dropout)
124        self.puerta_atencion = _CompuertaSuma(d, dropout)
125        self.posicion = _GRN(d, d, d, dropout)
126        self.puerta_final = _CompuertaSuma(d, dropout)
127        self.salida = nn.Linear(d, 1)
128        nn.init.zeros_(self.salida.bias)
129        pos = torch.arange(L + H)
130        self.register_buffer("mascara", pos[None, :] <= pos[L:, None], persistent=False)    # (H, L + H): cada hora futura ve hasta sí misma
131
132    def forward(self, x, cal_p, cal_f, dia):
133        pasado, self.pesos_pasado = self.sel_pasado(torch.cat([x, cal_p], dim=2))            # (B, L, d)
134        futuro, self.pesos_futuro = self.sel_futuro(cal_f)                                  # (B, H, d)
135        enc, estado = self.codificador(pasado)
136        dec, _ = self.decodificador(futuro, estado)
137        phi = self.puerta_lstm(torch.cat([enc, dec], dim=1), torch.cat([pasado, futuro], dim=1))   # (B, L + H, d)
138        theta = self.enriquecimiento(phi)
139        delta = self.puerta_atencion(self.atencion(theta[:, self.L:], theta, self.mascara), theta[:, self.L:])
140        psi = self.puerta_final(self.posicion(delta), phi[:, self.L:])
141        return 1.0 + self.salida(psi).squeeze(-1)
142
143    def diagnostico(self) -> dict:
144        return {}
145
146    def n_parametros(self) -> int:
147        return sum(v.numel() for v in self.parameters() if v.requires_grad)

Pipeline de entrenamiento y prueba#

Comandos de entrenamiento y evaluación#

Validación temporal de la configuración seleccionada:

python scripts/entrenar_arquitectura.py --modelo tft --anio 2021 --semilla 1000 --dispositivo auto --salida salidas/tft_validacion_1000

Comprobación funcional breve:

python scripts/entrenar_arquitectura.py --modelo tft --smoke --dispositivo cpu --salida salidas/tft_funcional

Evaluación final autorizada, con ajuste y parada anteriores a 2022:

python scripts/entrenar_arquitectura.py --modelo tft --fase prueba --allow-test --semilla 1000 --dispositivo auto --salida salidas/tft_prueba_1000

El código completo de preparación, optimización, guardado y restauración está en el pipeline ejecutable compartido. Cada salida debe ser una carpeta nueva.

El pipeline fija el plan y las huellas de entrada, genera ventanas cronológicas, ajusta las transformaciones por pliegue y evalúa 20 candidatos en 2018. Confirma cinco finalistas en 2019–2021, selecciona por MASE medio y reajusta con cinco semillas finales usando la reserva interna anterior a 2022. La lectura de la prueba solo ocurre después de cerrar la selección. El libro muestra las implementaciones y no llama al entrenamiento.

 29def sha256(ruta: Path) -> str:
 30    h = hashlib.sha256()
 31    with open(ruta, "rb") as f:

102        return pos[ok]

118        return ((self.indice[pos].normalize() - self.dia_base) / pd.Timedelta(days=1)).round().astype("int64").to_numpy()

120    # ------------------------------------------------------------------- escalas
121    def ajustar_escalas(self, pos_tr: np.ndarray) -> dict:
122        """Estadísticos estimados solo con las filas de historia de los orígenes de ajuste."""
123        a, b = int(pos_tr.min()) - self.L, int(pos_tr.max())  # filas [a, b): historia de todos los orígenes de ajuste
124        Xa, Ka = self.X[a:b], self.K[a:b]
125        sin_datos = np.isnan(Xa).all(axis=0)
126        with np.errstate(all="ignore"):
127            mediana = np.where(sin_datos, 0.0, np.nanmedian(np.where(sin_datos, 0.0, Xa), axis=0))
128            media = np.where(sin_datos, 0.0, np.nanmean(np.where(sin_datos, 0.0, Xa), axis=0))
129            std = np.where(sin_datos, 1.0, np.nanstd(np.where(sin_datos, 0.0, Xa), axis=0, ddof=1))
130        std = np.where(std > 0, std, 1.0)
131        mc, sc = Ka.mean(axis=0), Ka.std(axis=0, ddof=1)
132        sc = np.where(sc > 0, sc, 1.0)
133        dem = self.X[pos_tr[:, None] + self._off_l, 0]
134        sigma = max(float((dem / dem.mean(axis=1, keepdims=True)).std()), 1e-6)
135        return dict(mediana=mediana, media=media, std=std, media_cal=mc, std_cal=sc, sigma_demanda=sigma,
136                    no_estimables=[c for c, s in zip(self.hist, sin_datos) if s],
137                    inicio_ajuste=str(self.indice[a]), fin_ajuste=str(self.indice[b - 1]), filas_ajuste=int(b - a))

139    def construir(self, pos: np.ndarray, esc: dict) -> Conjunto:
140        pos = np.asarray(pos)
141        il, ih = pos[:, None] + self._off_l, pos[:, None] + self._off_h
142        xw = self.X[il]                                    # (n, L, n_hist); solo filas anteriores al origen
143        mascara = self.M[il]
144        xw = np.where(np.isnan(xw), esc["mediana"], xw)
145        nivel = xw[:, :, 0].mean(axis=1)
146        x = (xw - esc["media"]) / esc["std"]
147        x[:, :, 0] = (xw[:, :, 0] / nivel[:, None] - 1.0) / esc["sigma_demanda"]
148        cal_p = (self.K[il] - esc["media_cal"]) / esc["std_cal"]
149        cal_f = (self.K[ih] - esc["media_cal"]) / esc["std_cal"]
150        return Conjunto(np.concatenate([x, mascara], axis=2).astype("float32"), cal_p.astype("float32"), cal_f.astype("float32"),
151                        self.Y[ih], nivel, self.indice[pos], self.dia_de(pos))
152
153    # ---------------------------------------------------------------- referencias
154    def ingenuos(self, pos: np.ndarray) -> dict[str, np.ndarray]:
155        """Ingenuos diario y semanal con la misma disponibilidad que los modelos (kWh)."""
156        lag = C.REZAGO_H["demanda_real"]
157        out = {}
158        for nombre, base in (("ingenuo_24h", 24), ("ingenuo_168h", 168)):
159            pred = np.zeros((len(pos), self.H))
160            for h in range(self.H):
161                k = int(np.ceil((h + 1 + lag) / base)) if base == 24 else 1
162                pred[:, h] = self.Y[pos + h - base * max(k, 1)]
163            out[nombre] = pred
164        return out
165
166    def mase_por_origen(self, y: np.ndarray, yhat: np.ndarray) -> np.ndarray:
167        return np.abs(y - yhat).mean(axis=1) / self.q168

Bucle de ajuste y predicción#

  1"""Entrenamiento de una red con las reglas del motor v3 del proyecto.
  2
  3AdamW, pérdida MAE sobre demanda / nivel, ReduceLROnPlateau(factor 0.5, paciencia 2), recorte
  4de gradiente, parada cuando la época es >= 10 y hay 6 épocas sin mejora relativa de 0.2 %,
  5y restauración del mejor estado absoluto en la parada interna.
  6"""
  7from __future__ import annotations
  8
  9import random
 10import time
 11
 12import numpy as np
 13import torch
 14from torch import nn

 17def fijar_semilla(semilla: int) -> None:
 18    random.seed(semilla)
 19    np.random.seed(semilla)
 20    torch.manual_seed(semilla)
 21    if torch.cuda.is_available():
 22        torch.cuda.manual_seed_all(semilla)
 23    torch.backends.cudnn.deterministic = True
 24    torch.backends.cudnn.benchmark = False
 25    try:
 26        torch.use_deterministic_algorithms(True, warn_only=True)
 27    except Exception:
 28        pass

 31def a_tensores(conj, dev) -> dict:
 32    return dict(x=torch.from_numpy(conj.x).to(dev), cal_p=torch.from_numpy(conj.cal_p).to(dev), cal_f=torch.from_numpy(conj.cal_f).to(dev),
 33                dia=torch.from_numpy(np.array(conj.dia, dtype="int64")).to(dev), y=torch.from_numpy(conj.y_norm).to(dev))

 35
 36def _salida(red, t, ix):
 37    return red(t["x"][ix], t["cal_p"][ix], t["cal_f"][ix], t["dia"][ix])

 40@torch.no_grad()
 41def predecir(red, t: dict, lote: int = 256) -> np.ndarray:
 42    """Predicción normalizada (demanda / nivel) en modo evaluación."""
 43    red.eval()
 44    n = len(t["y"])
 45    partes = [_salida(red, t, slice(i, i + lote)).float().cpu().numpy() for i in range(0, n, lote)]
 46    return np.concatenate(partes, axis=0)
 47
 48
 49@torch.no_grad()
 50def _perdida(red, t: dict, lote: int = 256) -> float:
 51    red.eval()
 52    n, tot = len(t["y"]), 0.0
 53    for i in range(0, n, lote):
 54        s = slice(i, i + lote)
 55        tot += float((_salida(red, t, s) - t["y"][s]).abs().mean()) * len(t["y"][s])
 56    return tot / n

 59def entrenar(red, tr: dict, es: dict, p: dict, semilla: int, opciones: dict, observador=None) -> dict:
 60    """Ajusta ``red`` con ``tr`` y detiene con ``es``. Devuelve la historia y deja en ``red`` el mejor estado."""
 61    dev = tr["x"].device
 62    perdida = nn.L1Loss()
 63    opt = torch.optim.AdamW(red.parameters(), lr=float(p["lr"]), weight_decay=float(p["weight_decay"]))
 64    plan = torch.optim.lr_scheduler.ReduceLROnPlateau(opt, factor=0.5, patience=2)
 65    mejor = referencia = float("inf")
 66    estado, sin_mejora, historia = None, 0, []
 67    gen = torch.Generator().manual_seed(int(semilla))
 68    lote, n = int(p["lote"]), len(tr["y"])
 69    t0 = time.time()
 70    for ep in range(1, int(opciones["max_epocas"]) + 1):
 71        red.train()
 72        tot = 0.0
 73        for ix in torch.randperm(n, generator=gen).split(lote):
 74            if len(ix) < 2:      # la normalización por lotes necesita más de una muestra
 75                continue
 76            ix = ix.to(dev)
 77            opt.zero_grad(set_to_none=True)
 78            loss = perdida(_salida(red, tr, ix), tr["y"][ix])
 79            if not torch.isfinite(loss):
 80                raise FloatingPointError("Pérdida no finita")
 81            loss.backward()
 82            nn.utils.clip_grad_norm_(red.parameters(), float(opciones["recorte_gradiente"]))
 83            opt.step()
 84            tot += float(loss.detach()) * len(ix)
 85        vl = _perdida(red, es, int(opciones.get("lote_evaluacion", 256)))
 86        historia.append(dict(epoca=ep, perdida_ajuste=tot / n, perdida_parada=vl, lr=opt.param_groups[0]["lr"], segundos=round(time.time() - t0, 1)))
 87        if vl < mejor:
 88            mejor = vl
 89            estado = {k: v.detach().clone() for k, v in red.state_dict().items()}
 90        if not np.isfinite(referencia) or vl < referencia - max(1e-6, 0.002 * abs(referencia)):
 91            referencia, sin_mejora = vl, 0
 92        else:
 93            sin_mejora += 1
 94        plan.step(vl)
 95        if observador is not None:
 96            observador(historia[-1])
 97        if ep >= int(opciones["min_epocas"]) and sin_mejora >= int(opciones["paciencia"]):
 98            break
 99    red.load_state_dict(estado)
100    return dict(epocas=len(historia), mejor_epoca=int(np.argmin([h["perdida_parada"] for h in historia]) + 1),
101                mejor_perdida_parada=float(mejor), historia=historia, segundos=round(time.time() - t0, 1))

 72def corrida(ctx: Contexto, variante: str, p: dict, semilla: int, clave_datos: str, pos: dict, carpeta: Path, nombre_ev: str,
 73            guardar_modelo: bool = False) -> dict:
 74    """Entrena una configuración con una semilla y evalúa en ``pos['ev']``. Reanudable."""
 75    carpeta = Path(carpeta)
 76    rr = carpeta / "resultado.json"
 77    etiqueta = f"{variante} cfg {p['id']:02d} semilla {semilla} {nombre_ev}"
 78    if rr.exists():
 79        if ctx.barra is not None:
 80            ctx.barra.update(1)
 81        return leer_json(rr)
 82    carpeta.mkdir(parents=True, exist_ok=True)
 83    datos = ctx.datos
 84    esc, conj = ctx.conjuntos(clave_datos, pos)
 85    texto = None
 86    if variante == "N+O":
 87        texto = dict(vectores=torch.from_numpy(ctx.texto["vectores"]), lista=torch.from_numpy(ctx.texto["lista"]))
 88    desc = torch.from_numpy(ctx.descripciones) if ctx.descripciones is not None else None
 89    dispositivos = [ctx.dispositivo] + (["cpu"] if ctx.dispositivo != "cpu" else [])
 90    for intento, dev in enumerate(dispositivos):
 91        try:
 92            motor.fijar_semilla(semilla)
 93            red = redes.construir(ctx.cfg["paquete"]["red"], p, conj["tr"].x.shape[2], conj["tr"].cal_p.shape[2], datos.L, datos.H, texto, desc).to(dev)
 94            tens = {k: motor.a_tensores(v, dev) for k, v in conj.items()}
 95
 96            def observador(h, _e=etiqueta):
 97                if ctx.barra is not None:
 98                    ctx.barra.set_postfix_str(f"{_e} | época {h['epoca']} | parada {h['perdida_parada']:.5f}", refresh=True)
 99
100            t0 = time.time()

105            mase_es = _evaluar(datos, red, conj["es"], tens["es"], le)[1]["MASE"]

116               origen_ajuste=[str(conj["tr"].origen[0]), str(conj["tr"].origen[-1])], origen_parada=[str(conj["es"].origen[0]), str(conj["es"].origen[-1])],
117               origen_evaluacion=[str(conj["ev"].origen[0]), str(conj["ev"].origen[-1])],

120    pd.DataFrame(info["historia"]).to_csv(carpeta / "historia.csv", index=False)

122                        y_kwh=conj["ev"].y.astype("float32"), mase_por_origen=datos.mase_por_origen(conj["ev"].y, yhat))
123    if guardar_modelo:
124        torch.save({k: v.cpu() for k, v in red.state_dict().items()}, carpeta / "modelo.pt")

192def bootstrap_bloques(dif: np.ndarray, base: np.ndarray, bloque: int, remuestreos: int, semilla: int) -> dict:
193    """Bootstrap circular por bloques de días para la diferencia pareada por origen (A - B) y su valor relativo a B."""
194    n = len(dif)
195    g = np.random.default_rng(semilla)
196    nb = int(np.ceil(n / bloque))
197    d_obs, b_obs = float(dif.mean()), float(base.mean())
198    md, mb = np.empty(remuestreos), np.empty(remuestreos)
199    for a in range(0, remuestreos, 500):
200        k = min(500, remuestreos - a)
201        ix = ((g.integers(0, n, size=(k, nb))[:, :, None] + np.arange(bloque)[None, None, :]) % n).reshape(k, -1)[:, :n]
202        md[a:a + k], mb[a:a + k] = dif[ix].mean(axis=1), base[ix].mean(axis=1)
203    rel = 100 * md / mb
204    return dict(bloque_dias=int(bloque), remuestreos=int(remuestreos), diferencia_MASE=d_obs, ic95_diferencia_MASE=[float(v) for v in np.percentile(md, [2.5, 97.5])],
205                diferencia_relativa_pct=100 * d_obs / b_obs, ic95_diferencia_relativa_pct=[float(v) for v in np.percentile(rel, [2.5, 97.5])],
206                p_bilateral_bootstrap=float((np.abs(md - d_obs) >= abs(d_obs)).mean()))

230    por_h = {}
231    for variante in ctx.cfg["variantes"]:
232        hs = [leer_json(ctx.salida / "final" / variante.replace("+", "_") / f"semilla_{s}" / "resultado.json")["mase_por_horizonte"] for s in semillas]
233        por_h[variante] = np.mean(hs, axis=0)
234    pd.DataFrame(dict(horizonte_h=np.arange(1, datos.H + 1), **{f"MASE_{v}": por_h[v] for v in por_h})).to_csv(ctx.salida / "final" / "mase_por_horizonte.csv", index=False)
235
236    resumen = dict(n_origenes_prueba=int(len(pos["ev"])), periodo_prueba=[origen[0], origen[-1]], semillas=list(map(int, semillas)), q168_kwh=datos.q168,
237                   referencias={k: float(v.mean()) for k, v in ing.items()}, variantes={})
238    for variante in ctx.cfg["variantes"]:
239        m = t.loc[t.variante == variante, "MASE"].to_numpy()
240        resumen["variantes"][variante] = dict(configuracion=por_id[elegidas[variante]], MASE_media_semillas=float(m.mean()),
241                                              MASE_desv_semillas=float(m.std(ddof=1)) if len(m) > 1 else None, MASE_por_semilla=[float(v) for v in m],
242                                              MAE_kwh_media=float(t.loc[t.variante == variante, "MAE_kwh"].mean()), MAPE_media=float(t.loc[t.variante == variante, "MAPE"].mean()))
243    if {"N", "N+O"} <= set(media):
244        inf = ctx.cfg["inferencia"]
245        rem = ctx.rapido["remuestreos"] if ctx.rapido else inf["remuestreos"]
246        dif = media["N+O"] - media["N"]
247        resumen["contraste_N+O_menos_N"] = dict(
248            definicion="diferencia pareada por origen de la pérdida MASE, promediada sobre semillas; relativa = 100 (MASE_N+O - MASE_N) / MASE_N; negativo favorece al texto",
249            margen_practico_pct=100 * inf["margen_relativo"], primario=bootstrap_bloques(dif, media["N"], inf["bloque_dias"], rem, inf["semilla_bootstrap"]),
250            sensibilidad=[bootstrap_bloques(dif, media["N"], b, rem, inf["semilla_bootstrap"]) for b in inf["sensibilidad_bloque_dias"]],
251            nota="Resultado descriptivo de este modelo. La inferencia del proyecto aplica Holm a la familia preregistrada de contrastes; el valor p de aquí no está ajustado.")
252    guardar_json(ctx.salida / "final" / "resumen_prueba.json", resumen)
253    return resumen
